# Account Privacy Management

A Python-based account management project exploring how user credentials can be stored, validated, encrypted, and managed securely.

## About the Project

This project was completed as part of my **Introduction to Computer Science** course (CS-111). It was a **two-person group project**, developed collaboratively with one other student.

The goal of the project was to apply introductory Python programming concepts to create an account management system. The program handles user creation and authentication while incorporating password encryption, validation, and account data storage.

## What We Did

- Developed an account management system with **user creation, authentication, and encrypted password storage**.
- Created dictionary and file-handling functions to store account credentials, generate unique usernames, and update persistent account information.
- Implemented password validation with multiple security requirements, including an **8-character minimum** and screening against **100 common passwords**.
- Integrated independently developed functions into a single modular program through collaborative debugging and code standardization.
- Tracked password age to determine when a user's password may need to be changed.
